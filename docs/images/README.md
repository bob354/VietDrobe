# Ảnh giao diện

Ảnh chụp ngày 2026-10-07 từ [bản demo VietDrobe](https://viet-drobe.vercel.app), ở viewport desktop rộng 1440 px. Ảnh giữ nguyên giao diện và nội dung thực tế, không có dữ liệu khách hàng hoặc thông tin quản trị.

| File | Màn hình / trạng thái |
|---|---|
| `brand-mark.svg` | Logo vector từ `frontend/components/brand-mark.tsx` |
| `landing-dark.png` | Trang chủ, chế độ tối, header và hero |
| `landing-light.png` | Trang chủ, chế độ sáng, header và hero |
| `catalog.png` | `/catalog`, lọc nhóm Áo Cổ Phục, dữ liệu đã tải |
| `suggestions.png` | `/suggest`, kết quả quiz mặc định: Tết, Streetwear, Tất Cả / Unisex |

Để cập nhật, dùng cùng viewport, đợi font/ảnh và API tải xong, rồi chụp các trạng thái trên. Giữ tên file để liên kết trong README tiếp tục hoạt động. Cập nhật ngày chụp khi thay ảnh.
